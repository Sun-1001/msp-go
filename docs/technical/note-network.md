# 个人笔记与知识关联

## 重构范围与数据策略

旧图谱横跨学生图谱、管理员节点/关系管理、Redux 状态、G6/Three 渲染器及 progress API。知识分类 ID 同时被练习、错题、每日题、DKT、画像、论坛和学习路径引用，不能直接删除这些学习证据。

- 新增独立 Note、NoteLink、NoteMaterial，全部以认证学生为所有者；管理员没有个人笔记管理入口。私人笔记、材料和只读课程目录不加入管理端 JSON 导入导出白名单，完整恢复使用 PostgreSQL 原生备份。
- 删除旧图谱和管理员知识节点 CRUD 的完整运行链路。课程分类与先修约束迁至独立的只读课程目录，保留 ID 和必要教学字段，不提供节点管理或图谱 API。
- 旧公共节点没有私人笔记所有权，不自动复制为学生笔记；旧图谱的展示属性及非先修关系退役。历史 SQL 迁移保持不可变，新迁移负责拆分和删除。
- 学生正文使用 Markdown 内部链接 `[显示文字](/notes/笔记ID)`；服务端同步解析链接，校验目标所有权，在同一事务保存笔记和关系。改名保留 ID；删除笔记将其他正文中的指向链接转为普通文字并递增 revision，级联清理关系。
- 笔记写入使用 revision 冲突检测和学生范围事务锁，防止并发覆盖及删除/建链竞争。每个学生最多 2000 篇笔记，每篇最多 100 个内部目标，正文最多 200000 字，标题最多 200 字。
- 材料复用已有上传签名校验、私有文档存储（本地或 private S3/七牛）及认证体系，只通过鉴权下载接口读取，不暴露对象 URL。现有资源模型面向教师发布与知识库共享，因此个人材料仅新增所有者元数据，不复用公开资源授权。支持 PDF、DOCX、TXT、Markdown；文本可导入正文，其他文件作为来源附件。上传不调用 AI 或向量入库。
- 前端复用现有配色、公共表单和错误组件。知识关联使用原生二维 SVG，支持拖拽、缩放、平移、搜索、全部/局部网络和笔记跳转，无 WebGL 依赖。

## 发布边界

升级前停止旧 API/worker，制作并验证完整 PostgreSQL 与上传存储备份。先执行前向迁移，再同步发布新 API 和前端；不得新旧应用混跑。需要回滚时恢复匹配的完整备份和应用版本，不重放或改写历史迁移账本。开发验证仅使用一次性测试数据库，不自动迁移共享数据库。

上传成功但笔记未保存的材料仍属于学生，可再次关联。删除笔记不会自动删除来源文件；文件保留和存储切换沿用既有私有存储边界。

## 接口契约

以下接口均要求已启用的学生身份，所有者取自认证上下文，忽略客户端自报身份。越权 ID 与不存在 ID 同样返回 404；管理员和教师返回 403，未登录返回 401。笔记、网络和文件响应禁止缓存。

| 方法与路径（前缀 `/api/v1`） | 用途 |
| --- | --- |
| `GET /notes?search=` | 标题/正文子串搜索，空查询列出本人笔记 |
| `POST /notes` | 创建笔记，`revision: 0` |
| `GET /notes/{id}` | 笔记详情 |
| `PUT /notes/{id}` | 保存正文与同步链接，要求当前 revision |
| `DELETE /notes/{id}?revision=` | 删除笔记、解除反向链接并递增受影响笔记版本 |
| `POST/DELETE /notes/{id}/links/{target}` | 显式添加/解除链接，请求体带 revision，同时更新正文 |
| `GET /notes/network` | 完整个人网络 |
| `GET /notes/{id}/network` | 当前笔记及直接引用/被引用笔记的局部网络 |
| `GET/POST /notes/materials` | 本人材料列表 / multipart 上传 file（最大 10 MiB） |
| `GET /notes/materials/{id}/file` | 重新鉴权的附件下载 |
| `GET /progress/concepts` | 练习选择器所需只读课程分类；与个人笔记无关 |

规范内部链接不解析代码块、行内代码、图片或转义文本。链接按笔记 ID 去重；显式保存包含不存在、他人或自身目标的链接时返回 422，整次写入回滚。过期 revision 返回 409，前端保留草稿供用户处理。列表按更新时间排序；网络节点按 ID 稳定排序，布局采用确定性分层与不连通分组排布。

## 验证与容量边界

2026-10-15 在一次性 PostgreSQL 18 库验证从 30 升级到 32、空库顺序建立全部版本及重复迁移无操作；模拟存储验证文件隐私与故障。临时测试覆盖跨学生读取/写入/网络/建链/材料拦截、教师/管理员拒绝、改名保链、删除清理、并发 revision 冲突、Markdown 代码排除和输入边界。笔记 application + HTTP 联合语句覆盖率 86.5%。临时测试源码按项目规范在验收后删除。

迁移后同时验证练习课程读取、DKT 外键写入、画像、题库分类匹配、每日题目标、学习上下文和论坛关联。前端 10 项临时测试通过，布局/网络/工作区语句覆盖率 91.15%，行覆盖率 98.03%。Playwright 使用模拟 HTTP 数据验证实际组件的拖拽、平移、缩放、重置、聚焦、节点/正文跳转、文本上传导入、建链、保存和 390px 响应式；真实数据库/API 流程由 PostgreSQL 集成测试覆盖，未调用外部对象存储服务。

最终 `go test ./...`（删除临时测试前）、`go build ./...`、`go vet ./...`、`npm run build`（包含 TypeScript 检查）、`npm run lint`、`git diff --check` 均通过。临时测试源码、预览入口和一次性数据库已清理；原有业务库未执行迁移。运行代码、菜单、路由和依赖清单无旧图谱引用；历史迁移、早期迁移账本校准工具和历史验收记录保留用于追溯。

删除 G6、Three、react-force-graph-3d、d3-force-3d、three-spritetext 及 Three 类型包，无新增依赖；锁文件共移除 124 个包。依赖审计仍报告其他现有生产依赖 9 项告警（2 high、3 moderate、4 low），涉及 axios、xmldom、KaTeX 与 mammoth 依赖链，需单独安排兼容性升级，不执行跨业务的强制升级。

原生 SVG 不增加图形依赖。每学生 2000 篇的布局唯一性与稳定性做自动验证；大量高密度连边的生产交互性能仍需按真实资料评测。文本导入限 UTF-8 Markdown/TXT，PDF/DOCX 作为附件，不声称 OCR 或自动摘要。材料没有独立删除入口，保留策略与容量需由部署运维持续关注。
