# 学生学习反馈验收 · 2026-10-08

## 结论

本次完成学生画像、针对性出题和学习追踪的工程闭环优化。新增的核心能力是：**给出推荐时同时保存推荐依据和可检查的成功标准，后续正式作答再更新下一步**。系统能够区分新题首答不足、近期错因、同日高分、跨时间正确、重复熟悉题和长期未练习，不再仅凭掌握度数值或完成 10 题就暗示掌握。

这是可验证的产品能力改进。当前阶段阈值和 `dkt-sakt-lite` 仍是启发式规则，未在真实学生数据上训练或校准；本次未证明学习增益，也不声称研究意义上的算法创新。

## 环境与数据

- 从干净工作区开始，基线提交 `5ff48f5`。无数据库结构变更，使用现有 `0001` 至 `0029` 迁移。
- 独立 PostgreSQL 18 + pgvector 容器，端口 `127.0.0.1:55439`，数据库 `feedback_eval`。未使用业务数据库或已有的其他评测容器。
- 自行生成 1 名教师、1 个班级、7 名学生、复合函数求导知识点、51 道历史题与 60 条历史作答；其中一名学生对同一道题重复作答 10 次。真实模型链路另产生 2 道题和 2 次正式提交；同 submission ID 重放不新增作答。
- 通用模型：用户指定服务的 `gpt-6.1-sol`；嵌入模型：用户指定服务的 `text-embedding-3-small`，实际维度 1536。只发送合成数学题和合成学习状态，凭据未写入文件或持久化配置。
- 公众号、消息外发、支付、正式课程数据和现网部署均不在验收范围。

## 发现与修复

| 原行为或缺口 | 本次结果 |
|---|---|
| 自主出题只有知识点、难度、题型，缺少当前学生证据 | 读取本人近期错因、错因子类、首答及间隔证据，按阶段生成，并避开近期题面 |
| 行动完成度只计题量，完成与掌握容易混淆 | 保留原任务进度，新增阶段、原因、下一步和成功标准；完成标签改为“题量已完成” |
| 无薄弱项时只有通用错题入口 | 优先保留进行中行动，再从薄弱、证据不足、优势知识点安排下一步 |
| 冷启动容易得到缺乏事实支撑的评价 | 未观测掌握度为空，先诊断，不把未知等同于零掌握 |
| 画像报告及部分统计展示知识点 ID | 展示知识点名称，原 ID 保留为身份；同名知识点不覆盖 |
| 读侧遗忘系数 0.05/天，提交先验另用 0.025/天 | 统一调用共享遗忘投影，避免“看到的起点”和提交更新起点不一致 |
| 报告可能混用全窗口首答与最近五题正确率 | 提示中给出明确分母、子集关系和置信度含义，并用真实报告复核 |

代码遵循现有 Exercise / Progress / Portrait 边界；读模型不创建新的掌握事实。生成题仍需独立求解复核，作答仍经过原判题、诊断、事务和幂等链路。

## 可复核场景

| 合成场景 | 期望与结果 |
|---|---|
| 无历史 | 诊断；未知掌握度为空，无其他学生数据 |
| 近期持续漏用链式法则 | 错因巩固；保留程序性错误和漏乘内层导数子类 |
| 同日 10 道正确首答 | 等待间隔验证，没有直接进入迁移 |
| 跨日正确首答 | 建议尝试迁移，同时保留“非掌握保证”的边界 |
| 同题重复 10 次 | 只计 1 道新题首答；仍需诊断性新题 |
| 距最新首答至少 7 天 | 保持检验，优先基础新题 |
| 第一次作答在 30 天窗口外 | 窗口内重做不计为新题 |
| 修改题库题面和概念 | 历史反馈仍使用作答时冻结字段 |
| 未来作答、诊断或 DKT 时间 | 不进入当前证据快照 |
| 双学生、重复提交、重复开始行动 | 生成题越权拒绝，提交不重复记账，进行中行动不重设基线 |

单元边界还覆盖同题面不同 ID、低权重复习、20 次截断、30 天边界、未知错因、非有限掌握度/置信度、读取取消与失败、手选难度、不可用模型，以及共享遗忘先验回归。

## 真实模型样本

两道选择题均由生产出题服务生成，并经过生产 Math Solver 独立复核后持久化：

1. 错因巩固题：`f(x)=ln(1+sin(x²))` 求导。正确结果为 `2x cos(x²)/(1+sin(x²))`；干扰项包含漏乘内层导数。故意提交错误选项后，诊断给出 `procedural / chain_rule_missing_inner_derivative`，解释漏掉 `2x`。生成及复核样本耗时约 35 秒。
2. 迁移题：`y=sin((2x+1)³)` 求 `y'(0)`。正确结果为 `6cos(1)`；相较历史的平方复合函数题，增加三角外层和导数值计算。正确提交后记录成功并更新 DKT。生成及复核样本耗时约 45 秒。

更新后的真实画像报告区分本周 `1/4` 正确、近 30 天 `3/11` 新题首答正确、最新最多 5 题 `20%` 正确，以及其中 `2` 次间隔正确，没有把这些指标相加或混为同一分母。给出了步骤修复、新题与至少 24 小时后复核的任务。最终一次报告调用约 41 秒。

嵌入适配器真实提交 3 段原创教学内容和 2 条中文查询，实际返回 1536 维向量。余弦排序的两个 top-1 均命中预期内容：链式法则漏乘内层导数、积分换元后的上下限。**2/2 只说明这个小样本连通且具备语义区分，不是全库检索质量指标**；本次没有开展 Qdrant 全流程入库检索验收。
